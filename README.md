# Asher - Offline HTML Games Collection

A collection of 300+ playable HTML5 games that work completely offline. Perfect for entertainment when you don't have internet access or want quick browser-based gaming.

## 🎮 Features

- **Completely Offline** - All games run locally in your browser, no internet required
- **No Installation** - Just open an HTML file in your browser and play
- **Diverse Collection** - Includes action, puzzle, sports, strategy, and casual games
- **Lightweight** - Self-contained HTML files with embedded assets

## 🚀 Quick Start

1. Clone this repository or download it
2. Navigate to the `offline/` folder
3. Open any `.html` or `.htm` file in your web browser
4. Start playing!

### Open in Browser
You can also access the full collection online at: **https://qorzl.github.io/Asher/**

## 🎯 How to Use

1. **Play Locally**: Download and open `offline/index.html` in your browser for a game menu
2. **Play Online**: Visit the GitHub Pages site above
3. **Include in Projects**: Embed individual games in your own projects

## 💾 Browser Compatibility

Games work best in modern browsers:
- Chrome/Chromium
- Firefox
- Safari
- Edge

Most games require JavaScript enabled.

## ⚠️ Notes

- These games are self-contained and work completely offline once loaded
- Save data is typically stored in browser local storage (persists between sessions)
- Some games may require reload if they don't load properly
- File sizes vary; larger games may take a moment to load
